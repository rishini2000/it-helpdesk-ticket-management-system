# IT Helpdesk Ticket Management System

A full-stack web application designed to streamline IT support operations by managing technical issues, support requests, ticket assignments, and resolutions.

## Project Overview

The IT Helpdesk Ticket Management System allows employees to report technical issues and enables IT support teams to manage, prioritize, assign, track, and resolve support tickets efficiently.

## User Roles

- **USER** – Create tickets and track their progress.
- **SUPPORT** – Manage assigned tickets, investigate issues, and provide resolutions.
- **ADMIN** – Manage users, categories, ticket assignments, and system operations.

## Main Features

- Authentication and authorization
- Role-based access control
- Ticket creation and management
- Ticket assignment and reassignment
- Ticket priority management
- Ticket status workflow
- Comments and communication
- Ticket history and audit tracking
- Dashboard and analytics
- User management
- Category management
- Notifications
